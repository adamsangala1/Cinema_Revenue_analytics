# 🎬 Cinemax - Analýza tržieb a výkonnosti (Dátový projekt)

Ahoj! Toto je môj praktický projekt, v ktorom som si prešiel celým dátovým procesom – od napísania SQL skriptov až po vytvorenie interaktívneho dashboardu v Power BI.

*Poznámka: Všetky použité dáta sú čisto fiktívne a vytvorené výhradne na študijné účely pre simuláciu reálneho biznis scenára.*

## 💡 O čom projekt je?
Cieľom bolo analyzovať tržby a návštevnosť v sieti kinosál Cinemax za obdobie Máj – September 2026. Chcel som zistiť, ktoré filmy najviac zarábajú, ako ľudia najčastejšie platia a ktoré sály sú najvyťaženejšie.

## 🛠️ Ako som postupoval:
1. **SQL skripty : V SQL som pripravil a agregoval dáta pre 5 samostatných tém (vývoj tržieb, kumulatívny nárast, spôsoby platby, top filmy a výkonnosť sál).
2. **Dátové výstupy: Výstupy z SQL dotazov som použil ako podkladové tabuľky pre Power BI.
3. **Power BI:
   - Naimportoval som dáta a nastavil vzťahy v dátovom modeli.
   - Vytvoril som potrebné DAX merania.
   - Navrhol som vlastný vizuálny dizajn (tmavomodrý banner, biele podkladové karty so zaoblenými rohmi a tematické ikony).
   - Všetky grafy som presne zarovnal pomocou pixelových súradníc pre čistý a symetrický vzhľad.

## 📊 Čo na dashboarde nájdeš:
- **Mesačné Tržby & Kumulatívny vývoj:** Sledovanie vývoja tržieb v jednotlivých mesiacoch.
- **Top Tržby Filmov:** Rebríček najziskovejších filmových titulov.
- **Spôsoby platby:** Podiel platieb kartou, online a v hotovosti.
- **Výkonnosť sál:** Porovnanie výkonnosti typov sál (IMAX, Standard 2D/3D) v jednotlivých mestách.
